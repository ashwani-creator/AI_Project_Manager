# AI_Project_Manager
AI Project Manager is a web-based application designed to help students manage their college projects, tasks, deadlines, and progress in one place. It also provides a faculty monitoring panel to track project completion, pending tasks, and project status.

The system includes a dashboard, task management, project tracking, deadline monitoring, progress reports, and an alert system that identifies projects requiring attention based on their progress and deadlines.

The main objective of this project is to make project management easier for students and help faculty monitor project progress more efficiently.
